# Design System: Enterprise, Not Vibecoded
Reference look: IBM Carbon, GitHub, GitLab. The result should look like an internal engineering tool a staff engineer would trust, not a landing page for an AI startup.

## Tokens (define as CSS variables in `globals.css`, expose through the Tailwind config)
Light theme:
- background #ffffff, layer-01 #f4f4f4, layer-02 #ffffff, border-subtle #e0e0e0, border-strong #8d8d8d
- text-primary #161616, text-secondary #525252, text-helper #6f6f6f
- accent #0f62fe, accent-hover #0050e6, link #0f62fe
- error #da1e28, success #198038, warning #8e6a00 (text) / #f1c21b (marker)

Dark theme (Carbon gray 100):
- background #161616, layer-01 #262626, layer-02 #393939, border-subtle #393939, border-strong #6f6f6f
- text-primary #f4f4f4, text-secondary #c6c6c6, text-helper #a8a8a8
- accent #0f62fe (buttons), link #78a9ff
- error #ff8389, success #42be65, warning #f1c21b

Honor `prefers-color-scheme` by default, and provide a manual light/dark toggle in the header that persists in `localStorage`.

## Rules
- 4px spacing grid. Border radius 0 to 2px on everything (buttons, inputs, panels). No pill shapes.
- Panels are defined by 1px borders and a layer background, not by shadows. Use no box shadows anywhere, except a focus ring.
- Type scale: page title 28px/36px weight 400, section title 16px/24px weight 600, body 14px/20px, helper and metadata 12px/16px, code 13px. Use at most two font weights (400, 600).
- Sentence case everywhere. No ALL CAPS labels, except a 12px uppercase tracking label for table column headers if needed.
- Left-aligned layout. Do not center body content. Max content width 1200px.
- Buttons: primary is solid #0f62fe with white text, 40px tall, square corners. Secondary is a 1px bordered button. Tertiary is a text link. Never use more than one primary button per view.
- Focus: 2px outline in the accent color with a 1px inset gap. All interactive elements are keyboard reachable with logical tab order.
- Motion: only 110-150ms opacity or color transitions on hover and focus. No bounce, scale, slide-in, or staggered entrance animations.
- Loading uses a plain 16px spinner or a progress step list. Use skeleton blocks (flat #e0e0e0 or #393939 rectangles, no shimmer gradient) for panels while their content loads.

## Banned patterns (do not use any of these)
Gradients of any kind, gradient text, glow or blur effects, glassmorphism, decorative blobs or background illustrations, emoji in the UI, sparkle icons, icons inside colored circles, rounded-xl or larger corners, floating cards with hover lift, bento grids, centered hero sections, marketing copy ("supercharge", "unlock", "magic", "revolutionary"), purple/indigo accent colors, auto-playing animation, and multiple competing accent colors.

## Copy
Plain and factual. Examples: "Analyze repository", "Reading key files", "3 of 5 files read". Footer note on the results page: "This guide is generated by an AI model from a sample of the repository's files. Verify details against the source."
